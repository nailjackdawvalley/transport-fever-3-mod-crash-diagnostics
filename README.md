## 📁 How It Works — Troubleshooting Workflow

1. Make a backup copy of the affected save before changing the mod list.
2. Open the official Transport Fever 3 known-issues list and check whether the specific mod conflict is marked fixed.
3. Update the game and the affected mod to versions that explicitly support each other.
4. Test a fresh unmodded world, then compare it with the existing modded save.
5. Disable recently added optional mods in small groups to isolate conflicts, without deleting files needed by the save.
6. Use the game’s built-in logs and the mod author’s issue tracker to report the mod versions and reproduction steps.

## 🛠️ Troubleshooting Notes
